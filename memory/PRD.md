## Descrição
Site de sinais premium para slots de cassino online com suporte a 9 plataformas de jogos diferentes.

## Funcionalidades Implementadas
- Animação de intro com logo JOGO CLUB
- Seletor de plataformas (AG, BG, WG, YG, DG, MG, EG, HG, FG)
- Dashboard de análise de sinais
- Gerador de sinais para diferentes slots
- Indicadores ao vivo (Online, Taxa de acertos, Usuários ativos)
- Footer com aviso de jogo responsável (18+)
- **Botão "Copiar Nome"** na página de sinal
- **Provedores:** PG, PP, Amigo Gaming, Microgaming, FA CHAI Gaming, Revenge
- **Lógica de plataformas:** AG/BG/WG usam jogos novos; outras usam jogos antigos
- **Taxa de acerto:** 80-99% (ajustada para ser mais realista)
