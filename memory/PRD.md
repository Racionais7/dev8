## Descrição
Site de sinais premium para slots de cassino online com suporte a 9 plataformas de jogos diferentes.

## Funcionalidades Implementadas
- Animação de intro com logo JOGO CLUB
- Seletor de plataformas (MGJOGO, EGJOGO, WGJOGO, BGJOGO, HAJOGO, FAJOGO, DGJOGO, YGJOGO, suitbet)
- Dashboard de análise de sinais
- Gerador de sinais para diferentes slots (PG, PP, Hacksaw)
- Indicadores ao vivo (Online, Taxa de acertos, Usuários ativos)
- Footer com aviso de jogo responsável (18+)

## Tech Stack
- Frontend: React 19 + TailwindCSS + Radix UI
- Build: CRACO (Create React App Configuration Override)
- Fonte: Poppins (Google Fonts)
