# JOGO CLUB - Sinais de Slots

Site de sinais premium para slots de cassino online.

## Funcionalidades

- 9 plataformas de jogos (AG, BG, WG, YG, DG, MG, EG, HG, FG)
- 6 provedores de jogos (PG, PP, Amigo, Microgaming, FA CHAI, Revenge)
- Sistema de análise de sinais em tempo real
- Botão de copiar nome do jogo
- Interface responsiva e moderna

## Tecnologias

- React 19
- TailwindCSS
- CRACO

## Instalação

```bash
cd frontend
yarn install
yarn start
```
